# Veraba – Boutique en ligne

Projet personnel de boutique en ligne de t-shirts, conçu et développé seul, du design jusqu'à la mise en ligne.
Paiements en mode test : aucun vrai achat n'est effectué.

🔗 **Démo en ligne :** https://veraba.onrender.com/

## Fonctionnalités
- Création de compte sécurisée et consentement RGPD
- Catalogue, favoris et panier avec code promo
- Paiement par carte via Stripe (mode test) et portefeuille de cartes
- Espace client : suivi des commandes, adresses
- Design responsive, du mobile au grand écran

## Technologies
Node.js · Express · MySQL · Stripe · HTML · CSS · JavaScript · Bootstrap · Render · Aiven
